%% ---------- SERVER ----------
namespace server {
  class GameServer {
    -GameState gameState
    -List~ClientHandler~ clients
    -PlayerColor hostColor
    -GameClock gameClock
    -PlayerColor pendingDrawOfferFrom
    +configure(timeControl, hostColor) void
    +start(port) void
    +stop() void
    +broadcastState() void
    +broadcastEnd() void
    +broadcastChat() void
    +notifyMoveMade(mover) void
    +finalizeDrawIfPending(color) bool
    +handleDisconnect(handler) void
  }
  class ClientHandler {
    -Socket socket
    -GameServer server
    -PlayerColor assignedColor
    -boolean connected
    +run() void
    +sendMessage(msg) void
    +handleResign() void
    +handleMove(msg) void

    +stop() void

🔗 Daftar Relasi Utama

  • Inheritance: Piece ◁ King, Queen, Rook, Bishop, Knight, Pawn
  • Composition: GameState ◆ board Piece[8][8]  |  GameServer ◆ GameState  |  GameServer ◇ ClientHandler (2)
  • Association: GameState → PlayerColor/GameStatus/TimeControl/DrawReason; Move → PieceType/PlayerColor; Message → MessageType; GameServer → GameClock; ClientHandler → GameServer; GameController → NetworkClient/BoardView/ClockPanel/MoveHistoryPanel; BotGameController → StockfishEngine/GameClock/BoardView
  • Dependency: BoardFactory ⇢ GameState/Piece; MoveValidator ⇢ GameState/Move; FenConverter ⇢ GameState/Move; NetworkClient ⇢ Message; HostSetup ⇢ GameServer; StockfishLocator ⇢ StockfishEngine
  • Patterns: Observer (GameServer→ClientHandler), State Machine (GameStatus), Command (Message), Factory (BoardFactory)
